---

## 📌 Sobre o Projeto

O **BMS Mobile** é a interface móvel do sistema de Automação Predial Integrada. Projetado na **New Architecture do React Native**, o aplicativo entrega controle tátil instantâneo para gestores prediais e usuários autorizados monitorarem iluminação, temperatura e segurança de onde estiverem.

## 🚀 Funcionalidades

- 🎛️ **Dashboard Interativo:** Status geral de cada andar, zona e dispositivo em tempo real.
- 🌡️ **Termostato Digital:** Ajuste de temperatura e modos de climatização por sala.
- 💡 **Controle de Iluminação:** Liga/desliga e ajuste de luminosidade em grupos ou individualmente.
- 🔔 **Alertas e Notificações:** Notificações em caso de consumo anômalo ou alertas de segurança.

## 🛠️ Tecnologias Utilizadas

- **React Native 0.77+** (New Architecture com pure CXX modules)
- **TypeScript**
- **CocoaPods & Gradle**

## ⚙️ Como Executar Localmente

```bash
# 1. Clone o repositório
git clone https://github.com/IuryAlmeidaDev/bms-mobile.git
cd bms-mobile/mobile-app

# 2. Instale dependências
npm install

# 3. Para iOS (macOS)
cd ios && pod install && cd ..
npm run ios

# 4. Para Android
npm run android
```
